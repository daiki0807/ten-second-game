# 10秒ぴったりゲーム

小学校の教室（大型テレビ・Chromebook・スマートフォン）でそのまま使える、10秒当てゲームです。  
HTML・CSS・JavaScript だけで動きます（外部ライブラリ・ログイン・ビルド作業は不要です）。

## 遊び方

1. 「スタート」を押すと、短い「ピッ」という合図音が鳴り、「スタート！」が一瞬表示されて計測が始まります。
2. 計測中は経過時間やカウントダウンが表示されません。心の中で10秒かぞえて、10秒だと思ったら「ストップ」を押します。
3. 記録と10秒との差が小数第2位まで表示されます。
   - 10秒より早い場合：`9.84秒` / `10秒まであと0.16秒`
   - 10秒を超えた場合：`10.16秒` / `10秒より0.16秒オーバー`
   - 表示上10.00秒の場合：`10.00秒` / `ぴったり！`
4. 「もう一回」を押すと最初の画面に戻り、何度でも遊べます。

### 操作方法

- **マウス・タッチ**：画面の大きなボタンを押します。
- **キーボード**：`Space` キー または `Enter` キーで「スタート」「ストップ」「もう一回」を操作できます（長押しによる連続切り替わりは防止しています）。

## ファイル構成

- `index.html`：画面の骨組み
- `style.css`：教室の大型テレビ・Chromebook・スマートフォン対応のスタイル
- `script.js`：計測（`performance.now()`）・合図音（Web Audio API）・画面切り替えの制御
- `README.md`：使い方と公開手順

## ローカルでの確認方法

フォルダ内で簡易サーバーを起動してブラウザで開きます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いて確認できます。

## GitHub Pages での公開手順

1. GitHub で公開リポジトリを作成し、`main` ブランチにこのフォルダのファイルをプッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選び、ブランチに `main`、フォルダに `/ (root)` を指定して **Save** を押します。
4. 数十秒〜数分後、`https://<GitHubユーザー名>.github.io/<リポジトリ名>/` で公開されます。
